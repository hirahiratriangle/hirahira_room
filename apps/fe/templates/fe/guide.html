試験と収録問題

{{ exam.name }}は、科目A 60問／90分・科目B 20問／100分。合格には両科目とも 600点／1,000点 以上が必要です。

収録問題は {{ question_total }} 問。ほかに計算問題が {{ template_total }} 型あり、毎回数値が変わります。

苦手分野の判定

3問以上解いた分野のうち，60％ に寄せて平滑化した正答率が 60％ を下回るものを苦手と判定し，ダッシュボードに苦手な順で並べます。 解答数が少ないうちに極端な判定にならないよう，平滑化してから比較しています。

「おまかせ」モードでは，苦手分野が本番の出題比率より高い頻度で出ます。 まだ手を付けていない分野も，実力が分からないので優先的に出題されます。

ID と記録

ID なしでそのまま使えます。苦手を重点的に出題し、学習モードも分野別の正答率も使えますが、 記録はこのブラウザの中だけで、ブラウザを閉じたり、しばらく使わなかったりすると消えます。

ID を作ると、解答の記録と分野ごとの理解度がその ID に残り、別の端末でも同じ ID を入れれば続きから使えます。 問題メールと合格の申告は ID があるときだけ使えます。ID を作る前の解答は引き継がれません。

ID をお持ちの方の入口は マイページ（/fe/mypage/） です。 ブックマークしておくと、次から ID を入れるだけで続きを開けます。URL に ID は入りません。

ID は hirahira_room のアカウントとは別のもので、合言葉はありません。 ID を知っている人は誰でもその ID で入れるので、人と同じ ID は使わないでください。 成績と出題設定は ID ごとに分かれ、問題集は全員で共通です。

解答の記録は、ID ごとの成績が分からない形に集計して、みんなの集計の表示と問題の改善に使います。運営は ID ごとの記録を見られます。
