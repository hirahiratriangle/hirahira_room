# spec 007：会社の職掌と経営KPI

状態：**実装済み（KPI と目標はすべて案）** ・ 2026年10月

## 構想との対応

| 項目 | 内容 |
|---|---|
| 対応するスライド | 6（個人の成長と会社の成長をつなぐ）、19（再利用できる記録）、20（組織の力と次のアサイン）、21（立場ごとの成長） |
| 立場 | 会社 |
| 支える判断 | 次に狙う案件、育成へ再投資する項目、資産にする経験、物差しの改訂 |
| 使うデータ（スライド9） | 承認した成長、一般化して公開された記録、改訂の提案、質問リスト。割合の分母に在籍人数と現場の業界 |
| 書く人の得 | メンバーが書く量は増えない。既にある記録から数える |

## 職掌（案）

| 職掌 | 責任を持つこと | KPI | 目標（案） | 支える判断 |
|---|---|---|---|---|
| 営業・事業企画 | 担える仕事の大きさを広げ、次に狙う案件を決める | リーダー枠を担える人の割合 | 30%以上 | 上の立場の案件を狙えるか |
| | | 質問リストの件数 | 10件以上 | 現場の教訓が入場前の確認に戻っているか |
| 人材開発 | 育成へ再投資する項目を決める | 成長した人の割合（直近3か月） | 30%以上 | 育成が止まっていないか |
| | | 層の薄い項目（レベル3以上が2人未満） | 3項目以下 | どこへ育成を再投資するか |
| ナレッジ管理 | 現場の経験を会社の資産に変える | 公開したナレッジ（直近3か月） | 3件以上 | 経験が資産になり続けているか |
| | | 業界カバー率 | 80%以上 | 得意な業界の知見が残っているか |
| 標準化 | 現場の教訓で物差しとテンプレートを育てる | 改訂提案の決定率 | 80%以上 | 現場の声を止めていないか |
| | | 改訂提案の採用率 | 50%以上 | 物差しが現場の教訓で育っているか |

### 使わない指標

個人別の売上・粗利の比較、個人別の稼働時間の比較（憲章 II）。実際の金額は別のシステムの話で、標準売上・標準粗利・稼働率を spec 008 で足した。

## ユーザーストーリー

- US1 会社の立場は、4つの職掌ごとに KPI と目標への到達を見る
- US2 会社の立場は、担える立場の推移・スキル項目ごとの人数・ナレッジの累計・改訂提案の状態をグラフで見る。同じ値を表でも読める
- US3 会社の立場は、指標の定義と目標（案）を確かめられる

## 受け入れ条件

1. `/genba/company/kpi/` に4職掌・8つの KPI・4つのグラフが出る。会社の立場の人だけが開ける
2. 現場名・個人名・記録の原文が画面に出ない（金額は spec 008 で全社と業界ごとに足した）
3. 数えるのは承認した成長と公開中の記録だけ。承認前の成長、公開をやめた記録は数えない
4. 過去の期間の値は、その時点の台帳から求める
5. 分母が0の KPI は「―」と出し、達成とも未達とも判定しない
6. デモデータで、スライド6・19・20・21の内容をグラフで説明できる

## 憲章チェック

- [x] I：入力欄を足さない。既にある記録から数える
- [x] II：人数と割合だけ。人を並べて比べない
- [x] IV：会社の列にあるデータだけを使う。週報・Issue・約束と実際は使わない
- [x] V：使う成長は承認したものだけ
- [x] VI：この spec では金額を扱わない（spec 008 で積み上げる）

## 作ってみて分かったこと（構想に戻す）

1. **職掌の担い手**：4つの職掌を誰が持つかは未定。デモでは会社の立場ひとりがすべて見ている。部署に割るときは、閲覧の範囲（決めること4）も合わせて決めたい
2. **目標の水準**：目標はすべて仮置き。実績が1年ほど溜まってから決め直したい
3. **現場の健全度は会社に見えない**：約束と実際のズレなどは経営にも効くが、公開範囲の表で会社の列が「―」なので使っていない。全社合計だけでも会社に見せるなら、憲章の改訂が要る
4. **定着率が測れない**：在籍の出入りを持っていない。人材開発の KPI に足すなら、在籍の記録をどこに持つかを決めたい
5. **公開の日付**：公開をやめて公開し直すと公開日が新しくなり、累計の推移がその分だけ変わる
