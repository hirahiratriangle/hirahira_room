# spec 006：成長の確定とスキル台帳

状態：**実装済み** ・ 2026年10月 ・ 構想書（2026年10月 更新版）に合わせる

## 構想との対応

| 項目 | 内容 |
|---|---|
| 対応するスライド | 4、6、8（原則04・05）、9（目標と成長の行）、18、20、21、22 |
| 立場 | メンバー（記入）、リーダー（確認）、マネジメント（承認）、会社（スキル台帳） |

## 変えること

| 項目 | これまで | 更新後 |
|---|---|---|
| 成長の確定 | 本人が依頼したときだけ課長が合意 | 記入（メンバー）→ 確認（リーダー）→ 承認（マネジメント） |
| ひとり現場 | なし | 確認するリーダーがいない現場は、マネジメントが確認と承認を行い、元請・顧客の声を残す |
| 成長の公開範囲 | 本人だけ | 現場チームは全文、マネジメントは確認後に個人ごと |
| 承認で決めること | ― | レベル・評価A〜E・次の目標 |
| 会社 | 合意した成長の匿名集計、本人が出したアサインの希望 | 個人のスキル台帳（項目×レベル、証拠、次の目標）、証拠つきスキルシート、台帳の集計 |
| 原則05 | 記録で人を採点しない | 成長を評価し、支援する。見るのは量ではなく成長 |

## 受け入れ条件

1. メンバーは成長を記入して確認を依頼できる。依頼中と承認後は書き換えられない。承認前なら取り下げられる
2. 同じ現場のリーダー（本人以外）が確認または差し戻しをする
3. マネジメントは確認済みの成長を承認または差し戻しをする。承認でレベル・評価・次の目標が決まる
4. 確認するリーダーがいない現場では、マネジメントが確認と承認を行い、元請・顧客の声を残せる
5. 現場チームは成長を読める。現場の外の人は読めない。マネジメントは確認待ちになる前の成長を読めない
6. 会社の画面に、承認した成長だけでスキル台帳とスキルシートが出る。承認していない成長は出ない
7. 自分の成長を自分で確認・承認できない
8. デモデータで、スライド20・22を画面で説明できる
