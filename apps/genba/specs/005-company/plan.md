# plan 005：会社

spec：[spec.md](spec.md)

## モデル（`0001_initial` を作り直す）

| モデル | 変更 |
|---|---|
| 公開できる記録（`KnowledgeMixin`） | 状態を「―／ナレッジ候補／会社公開」にする。一般化した版 `public_title`・`public_body`、`published_by`・`published_at` を足す |
| `Goal` | 次の目標 `next_text`、アサインの希望として会社に出す `share_next`・`shared_at` |
| `KitProposal`（新規） | 改訂の提案：対象（チェックリスト／言い回し集／スキルセット）・題・提案・理由・状態（提案中／採用／見送り）・決めた人 |
| `InterviewQuestion`（新規） | 営業・面談の質問リスト：質問・業界・元になった振り返り（任意） |

## 画面

| URL | 画面 |
|---|---|
| `/genba/knowledge/<doc|term>/<id>/publish/` | 一般化して公開（リーダー）：原文を見ながら一般化した版を書く |
| `/genba/company/` | 会社：ナレッジ資産（用語辞書・先例・振り返り・面談メモ・質問リスト・改訂の提案）、組織の力（スキル分布・ITSS相当・複雑性・薄い項目）、アサインの希望、成長のつながり |
| `/genba/kit/proposals/create/?target=...` | 改訂の提案（誰でも）。テンプレート・言い回し集・スキルセットの画面から移れる |
| 成長を説明する画面 | 次の目標とアサインの希望 |

## 集計（`growth.py`）

- `skill_distribution()`：合意した成長を、本人×項目ごとに最新の1件にして、項目×レベルの人数にする
- `itss_distribution()`・`complexity_experience()`：合意した成長の ITSS 相当と複雑性
- `thin_items()`：レベル3以上の人数が最も少ない項目

## テスト

- 公開：本人は公開できない、リーダーが一般化した版で公開、会社には一般化した版だけ、公開をやめる
- 分布：合意だけを数える、同じ人の同じ項目は最新の1件、名前が出ない
- アサインの希望：出したものだけ
- 改訂の提案：誰でも出せ、会社の立場だけが決められる
- 質問リスト：会社の立場だけが足せる
