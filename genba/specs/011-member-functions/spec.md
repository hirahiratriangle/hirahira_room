# spec 011：メンバーの職掌

状態：**実装済み（案）** ・ 2026年10月

## 構想との対応

| 項目 | 内容 |
|---|---|
| 対応するスライド | 12（メンバー支援）、13・14（成長基軸）、21（立場ごとの成長） |
| 立場 | メンバー |
| 支える判断 | 自分は何を確かめ、どこで止まっているか |
| 使うデータ（スライド9） | 本人の記録 |
| 書く人の得 | メンバーが書く量は増えない。自分の状況が1画面で確かめられる |

## リーダーとの違い

リーダーはチームが止まらないように支える。メンバーは担当の成果物をやり遂げ、そのために状況を早く見せる。

| 観点 | リーダー | メンバー |
|---|---|---|
| 問い | 今日、誰が何で止まっているか | 自分は何を確かめ、どこで止まっているか |
| 決めるもの | 説明の時間、公開する記録 | 裁量の範囲での進め方、次の目標 |
| 見る単位 | 自分の現場 | 自分 |
| 責任 | チームの成果物 | 担当の成果物 |
| 成長への関わり | 事実を確認する | 行動と証拠を書く |

## 職掌（案）

| 職掌 | 責任を持つこと | 確かめる数字 |
|---|---|---|
| 現場の理解 | 全体像と担当機能をつかみ、理解を形にする | 入場時チェックリストの進み具合、1週目のまとめ |
| 担当の遂行 | 自分の作業を予定どおりやり遂げ、遅れは早く伝える | 予定どおり終えた作業の割合、予定日を過ぎた作業 |
| 状況の共有 | 読めないことや懸念を早く上げ、週報と人月を出す | 先週の週報、今月の人月、今出ている危険信号 |
| 自分の成長 | 目標を立て、行動と証拠で成長を説明する | 目標の段階、次の目標 |

## 決めたこと

1. 本人にだけ見せる。リーダーを含む他の人の画面に、人ごとに出さない
2. 記録の量は数えない。「やったか」「どの段階か」だけを見る
3. 目標の数値と「未達」の表示を使わない。「済み」「これから」で出す
4. 現場ごとに出し、全社の数字と質問リストは参考として下に置く

## 受け入れ条件

1. メンバーの `/genba/kpi/` に、動いている現場ごとの4職掌が先に出て、全社の数字は参考として下に出る
2. 本人の記録だけを数え、他の人の画面に出ない
3. メンバーの4職掌に目標の数値と「未達」が出ない
4. 標準売上・標準粗利・稼働率・在籍人数・成長した人の割合が出ない

## 作ってみて分かったこと（構想に戻す）

1. **リーダーがメンバーでもある現場**：リーダーを兼ねる人には、リーダーの職掌を出す。別の現場でメンバーとして入っている分は、今は出ていない
2. **チェックリストの済み**：リーダーやメンバーの全員に同じ項目が並ぶので、入場の時期によって進み具合の意味が変わる。比べないことで避けている
