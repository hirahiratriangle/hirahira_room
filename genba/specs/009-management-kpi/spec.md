# spec 009：マネジメントの職掌とKPI

状態：**実装済み（KPI と目標は案）** ・ 2026年10月

## 構想との対応

| 項目 | 内容 |
|---|---|
| 対応するスライド | 18（現場単位の指標で、手を打つ現場を決める）、21（立場ごとの成長）、22（成長の確定） |
| 立場 | マネジメント |
| 支える判断 | どの現場に手を打つか、成長の確定を止めていないか、誰をどこへ動かすか、約束を直すか |
| 使うデータ（スライド9） | 現場単位の運営指標、承認の状態と次の目標、月次の人月と在籍人数 |
| 書く人の得 | メンバーが書く量は増えない。既にある記録から数える |

## 会社との違い

会社は物差しと方針を決める。マネジメントはその物差しで、今の現場と人を動かす。

| 観点 | 会社 | マネジメント |
|---|---|---|
| 問い | どこへ向かうか | 今どの現場と誰に手を打つか |
| 決めるもの | 階級表、目標、育成の方針、物差しの改訂 | 手を打つ現場、成長の承認、次のアサイン |
| 見る単位 | 全社・業界 | 現場・個人 |
| 時間の幅 | 四半期〜年 | 週〜月 |

## 職掌（案）

| 職掌 | 責任を持つこと | KPI | 目標（案） |
|---|---|---|---|
| 現場の運営 | 兆候を見つけ、手を打つ現場を決める | 兆候が出ている現場の割合 | 25%以下 |
| 人の成長の確定 | 成長を確かめて承認し、次の目標を示す。ひとり現場の確認も担う | 承認待ちの平均日数 | 7日以下 |
| アサイン | 次の目標に合う現場へ人を動かす | 次の目標を持つ人の割合 | 50%以上 |
| | | 稼働率 | 90%以上 |
| 約束の調整 | 営業時の約束と現場の実態のズレを、顧客や営業と直す | 約束と実際のズレ | 3件以下 |
| | | スコープ外の件数 | 5件以下 |

## 会社とのつながり

- 承認した成長 → リーダー枠の割合、層の薄い項目
- アサイン → 稼働率、標準売上
- 約束の調整 → 質問リスト、改訂の提案

## 受け入れ条件

1. マネジメントの `/genba/kpi/` に4職掌が先に出て、会社の KPI は参考として下に出る
2. 他の立場の画面に、この4職掌は出ない
3. Archive した現場は数えない
4. 確認が済んでいない成長は、ひとり現場を除いて承認待ちに数えない
5. 人は人数と割合だけで数え、人を並べて比べない

## 作ってみて分かったこと（構想に戻す）

1. **見る範囲**：デモのマネジメントは1人で全現場を見ている。チームごとに課長を置くなら、見る範囲をチーム単位に絞る必要がある
2. **アサインの質**：「次の目標に合う現場へ動かせたか」は今の記録では測れない。次の目標を持つ人の割合で代えている
3. **目標の水準**：件数の目標は現場の数で変わる。現場が増えたら、1現場あたりの値に改めたい
