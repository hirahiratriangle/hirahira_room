# spec 003：リーダー画面（メンバーの管理）

状態：**実装済み** ・ 2026年10月

## 構想との対応

| 項目 | 内容 |
|---|---|
| 対応するスライド | 17（リーダー：作業量ではなく、詰まりを早く見つける）、16 の「genba での扱い」列（読めない Issue がリーダーに見える、週報が途切れるとリーダーに表示） |
| 立場 | リーダー（担当する現場の全文を読む） |
| 支える判断 | 誰がどこで詰まっているか。どこに説明の時間を割くか。メンバーの理解は期待とずれていないか |
| 使うデータ（スライド9） | 週報・Issue・まとめ・体制（裁量の線）。すべて現場チーム内 |
| 公開範囲 | 現場チーム内。リーダーが書いた返し（説明の時間、まとめへの返し、懸念への返事）はメンバーにも見える |

## 書く人の得

- メンバーが「読めない」や懸念を書くと、リーダーが説明の時間や返事を返す。**書いたことに反応が返ってくる**
- 1週目のまとめに、スキルの具体記述に沿った差と次の作業が返ってくる（目標を立てていれば、その記述と並べて見られる）
- 裁量の線を一度言葉にしておくと、毎回相談するか迷わない

## ユーザーストーリー（スライド17の6つ＋スライド16）

### US1 詰まりの一覧

- 担当現場のメンバーごとに、未解決の Issue と止まっている日数（最長の日数で並べる）
- 週報が前週に出ていないメンバーに「週報が途切れている」を出す（スライド16「指摘も指示も来ない」）
- 作業量（記録の件数、チェックリストの進み具合）は出さない

### US2 「読めない」の受け取り

- 担当現場の未解決の「読めない」を一覧にし、2日動かないものを強調する
- リーダーは「説明の時間」（日付とメモ）を割り当てる。メンバーの Issue にも見える

### US3 1週目のまとめ確認

- 出されたまとめのうち、まだ返していないものを一覧にする
- まとめの画面で、メンバーの目標（立てていれば）とその項目のレベル別の具体記述を並べて見ながら、**差と次の作業**を返す。メンバーのまとめの画面に出る

### US4 週次共有の一覧

- 週を選ぶと、メンバーの週報の「やったこと・分かったこと・詰まっていること・次にやること」を横に並べる（現場チームの誰でも見られる）

### US5 裁量の線の記録

- メンバーごとに「自分で決める範囲」と「相談して決める範囲」を一度言葉にして残す。本人とリーダーが書ける
- リーダー画面には、まだ線を引いていないメンバーを出す

### US6 懸念の受け取り

- 事実・解釈・未確認に分かれた懸念（課題 Issue）を、影響と一緒に一覧にする
- リーダーは「受け取った」と返事を書く。まだ受け取っていないものを強調する

## 受け入れ条件

1. リーダー画面に、担当現場ごとの6つの欄（詰まり、読めない、まとめ確認、週次共有、裁量の線、懸念）と、これまでのナレッジ候補が出る
2. 週報が前週に出ていないメンバーが、詰まりの欄に出る
3. 「読めない」に説明の時間を割り当てられ、メンバーの Issue の画面に出る
4. まとめに差と次の作業を返せ、メンバーのまとめの画面に出る。目標の具体記述が並んで見える
5. 週次共有の一覧で、週ごとにメンバーの週報4欄を横に並べて見られる
6. 裁量の線を本人とリーダーが書け、他のメンバーは書けない
7. 懸念に返事を書くと「受け取った」になり、メンバーの Issue の画面に出る
8. リーダーでない人は、説明の時間・まとめへの返し・懸念への返事を書けない
9. 人ごとの記録の件数や作業量を出さない（憲章 II）
10. デモデータで、スライド17の内容を画面で説明できる

## 範囲外

- リーダー自身の成長（スライド21のリーダーの列）は spec 005
- 複数現場の横断（マネジメント）は spec 004

## 憲章チェック

- [x] I：メンバーが新しく書くものはない（裁量の線は一度だけ）。書いたものに反応が返る
- [x] II：詰まり（止まっている日数）と週報の途切れだけを見る。作業量・件数は出さない
- [x] III・IV：すべて現場チーム内
- [x] V：まとめへの返しは差と次の作業。点数や評価は付けない
- [x] VI：該当なし

## 作ってみて分かったこと（構想に戻す）

1. **リーダー自身の記録はリーダー画面に出していない**：リーダーも現場のメンバーとして詰まりや懸念を書く。リーダー自身の懸念は誰が受け取るか（マネジメントか）を決めたい
2. **「週報が途切れている」は人ごとの表示になる**：構想書スライド16のとおりリーダーにだけ出しているが、憲章 II（人ではなく現場を測る）との線引きとして、「件数ではなく、途切れたという事実だけを出す」でよいか確かめたい
