# plan 004：運営指標

spec：[spec.md](spec.md)

- モデル `StructureGap`（新規）：`site`・`author`・`role_kind`（指示者／決裁者）・`on_chart`（体制図では）・`actual`（実際は）・`created_at`。`0001_initial` を作り直す
- `kit`：記録を残す場所に「体制のズレ」を足し、危険信号「日々の指示者が体制図と違う」の移り先にする
- `signals.weeks_missing_in_row(membership)`：前週からさかのぼって、週報が続けて出ていない週の数（入場前の週は数えない）
- `metrics`：体制のズレ、リーダーの懸念（未解決・未受け取り）、週報の途切れが続いている人数を足す。目安：体制のズレ1件、リーダーの懸念2件、途切れの継続1人
- 懸念を受け取る人：書いた人がリーダーなら同じ現場の他のメンバー、そうでなければリーダー（書いた本人は受け取れない）
- 画面：マネジメントの表を8指標にし、指標の定義表を足す。現場のページに「体制のズレ」タブと「リーダーからの懸念」。メンバーのホームに「リーダーからの懸念」。リーダー画面に「マネジメントにも届いている」
- テスト：体制のズレの記録、8指標の計算、マネジメントの画面に名前・原文が出ないこと、懸念を受け取れる人、途切れ1週と2週
