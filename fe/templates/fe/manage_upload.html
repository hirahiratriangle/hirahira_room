キャンセル
書式
[
 {
  "category": 11,
  "subject": "A",
  "topic": "情報セキュリティ",
  "difficulty": 2,
  "stem": "問題文",
  "choices": ["ア の本文", "イ の本文", "ウ の本文", "エ の本文"],
  "answer": 0,
  "explanation": "解説",
  "source": "出典・根拠"
 }
]
キーはアプリが払い出すので書く必要はありません。 choices に記号（ア／イ）は入れない。answer は 0 から数える。category は中分類の番号（1〜23）。 科目Aは四肢択一、科目Bは本番でも6〜10択が普通。
